# AGENTS.md

This file provides guidance to Codex (Codex.ai/code) when working with code in this repository.

## Project overview

A course registration automation tool for Jinan University's教务系统 (jwxk.jnu.edu.cn). Submits repeated volunteer-based course selection requests to improve chances of getting into popular courses.

## Two-phase workflow

1. **Authenticate** — `get_cookies.py` opens Chrome via Selenium, the user manually logs in, then the script extracts and validates cookies + token, fetches student info (including available elective batch codes), saving everything to local JSON files.
2. **Submit requests** — `jwxk.py` reads `student_info.json` for the student code and `course_batch.json` for the per-course batch mapping, then loops infinitely, POSTing to the volunteer endpoint with each course's matching batch code at ~1 req/s.

## Key configuration

- **`student_info.json`** (generated by `get_cookies.py`): Contains the student code (`code` field) and all available elective batch codes (`electiveBatchList` — each entry has `code`, `name`, `typeName`, `beginTime`, `endTime`).
- **`course_batch.json`** (user-edited): Maps teaching class IDs to their corresponding elective batch codes. Each course may belong to a different batch (e.g., major courses vs. general electives). Example:
  ```json
  {"2627106446": "fef5960ba85e4e96a66c295e5a3fd217", "2627106076": "0b215876e50f4bd192016ad490e5ed4c"}
  ```
  Batch codes are found in `student_info.json` → `electiveBatchList`. The user determines which batch each course belongs to and edits this file accordingly.
- `time.sleep(1)` (line ~210 in `jwxk.py`, **commented out by default**): Throttle interval between requests. Uncomment to enable rate limiting.

## Running

```bash
# Install dependencies
pip install requests selenium

# Step 1: Open browser, log in, save credentials + student info
python get_cookies.py

# Step 2: Edit course_batch.json — for each target course, fill in its batch code
#         (batch codes are in student_info.json → electiveBatchList)

# Step 3: Start the registration loop
python jwxk.py
```

Credentials must be fresh — logging in elsewhere invalidates them. If `jwxk.py` reports "未查询到登录信息", delete `cookies.json` and `token.json` and re-run `get_cookies.py`.

### Verify the script works before the registration window

Run `jwxk.py` before the selection period opens. If the response `msg` is "当前时间不在选课开放时间范围内", the script is configured correctly. Any other message warrants checking your setup.

### Response codes

| Code | Meaning |
|---|---|
| `"1"` | Request accepted / success |
| `"2"` + "该课程已经存在选课结果中" | Course already in your selection results |
| `"302"` + "身份不一致" | Usually caused by invalid login state — re-run `get_cookies.py` |
| `msg = "未查询到登录信息"` | Session expired — delete `cookies.json`/`token.json` and re-authenticate |

### Field naming caveat

`student_info.json` uses `code` for two different things:
- **Top-level `code`**: the student's 10-digit 学号 (used as `studentCode` in POST payloads)
- **`electiveBatchList[].code`**: a 32-char hex UUID identifying the selection round (used as `electiveBatchCode` in POST payloads)

The `isMajor` field in volunteer payloads distinguishes 专业课 (`"1"`) from 通选课 (`"0"`).

## Login validation logic (`get_cookies.py`)

`validate_login_state()` probes three API endpoints (`volunteered.do`, `publicCourse.do`, `studentstatus.do`) because which endpoints exist varies by semester. It considers the session valid if **any** endpoint returns a non-"未登录" response — a single 404 is not fatal.

## API base

`https://jwxk.jnu.edu.cn/xsxkapp/sys/xsxkapp/elective/` — the volunteer endpoint is `volunteer.do`, the status check is `volunteered.do`.

## Student info endpoint

`GET https://jwxk.jnu.edu.cn/xsxkapp/sys/xsxkapp/student/{studentCode}.do?timestamp=1` — returns student profile and `electiveBatchList` (all available selection rounds with their `code`, `name`, `typeName`, `beginTime`, `endTime`). `get_cookies.py` calls this after login and saves the result to `student_info.json`. The `electiveBatchList` is the authoritative source for per-semester batch codes — no more manual network-tab inspection needed.
